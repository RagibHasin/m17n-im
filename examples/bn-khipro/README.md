# bn-khipro m17n input method in Rust

It contains mechanically generated Rust version of [Khipro](https://github.com/KhiproTeam/) Classic and Dark input methods from a local copy. The codegen happens automatically at build time.

It currently tracks [v37.0.3](https://github.com/rank-coder/khipro-m17n/releases/tag/clsc-v37.0.3) of Khipro Classic and [v2.0.2](https://github.com/KhiproTeam/khipro-dark-m17n/releases/tag/drk-v2.0.2) of Khipro Dark.

For more information visit [KhiproTeam](https://khipro.khiproteam.com/)'s website.
